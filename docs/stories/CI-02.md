# CI-02 — Comparable finding sets classified by stable identity

**Issue:** [#37](https://github.com/anthonygraca/gherkin-knowledge-graph/issues/37) · **Parent:** F-10
[#16] · **Milestone:** M4 · **Owner:** shared.
**Canonical criteria:** [CI-02.feature](CI-02.feature) (refinement draft, 6 scenarios).
**Status:** specification ready for review; implementation follows CI-01 and the M3 gate. Portable
source-locator comparison needs the owner disposition in ADR 0012.

## Scope

Diff complete, comparable, revision-bound reports using the existing fingerprint; new/unchanged/resolved;
unchanged before/after payloads retained; refuse missing revisions, incomplete reports, differing
repositories/scopes/policies, contradictory baselines, and portable locator identities without a reviewed
continuity mapping.

## Non-goals

Requirement verdicts, automatic finding closure, policy migration, inferred rename continuity, rewriting
findings.

## Verification plan (planned, not executed)

Banking fixture yields 2 new / 4 unchanged forward and 2 resolved reverse; self-comparison unchanged;
payload-only changes stay unchanged; invalid comparisons exit 2 with `findings-not-comparable`; portable
locator case refuses classification.
