## Source and rationale

The repository owner asked that CTA be developed through the full lifecycle — stakeholder needs,
system obligations, story refinement with Gherkin acceptance criteria, design, implementation,
verification, validation, release and maintenance — with the project's own traceability discipline
exercised as it is expected of its users. The convention is recorded in
[development-lifecycle.md](../development-lifecycle.md); the roadmap carries the delivery-level
statement in *"Developing CTA with its own traceability discipline"*; the draft
[project definition](../project-definition.md) is the first lifecycle artifact. As an
engineering-convention story it traces to that process constraint rather than to a fabricated
end-user requirement (see activity 4 in the lifecycle document).

**Retrospective attribution.** The convention documents and the M0 criteria migration already
existed as working-tree changes before this story was created. The author record
[lifecycle-specification-migration.md](../reviews/lifecycle-specification-migration.md) cites
SETUP-01 (#8), FT-01 (#18) and FT-02 (#19) as the items served at the time it was written; FT-03
is added prospectively and rewrites nothing. No execution, review or approval is inferred for the
earlier work, and the migration does not amend M0's approved exit criteria or its approved
snapshot.

## Non-goals

* No Gherkin runner, step bindings, BDD framework or new CI gate. Selecting tooling and binding
  steps needs its own scoped story and an ADR; unbound scenarios are never reported as executed.
* No new product behavior, API, contract, fixture or schema change, and no later-milestone work.
* No requirement approval: REQ-101–REQ-108 remain discussion candidates for owner/team review.
* No retroactive scenario IDs in historical execution records; earlier run records keep the
  revision and labels they were produced under.
* No automated traceability gate, parser or database; the verification map stays Markdown.
* No graph, vector-store, model-provider or benchmark-tooling choice, and no self-ingestion
  before the product supports it.

Notes and limitations:

* The P1 "before" side is read from `git show efa824b5:docs/stories/M0-foundation.md`, so the
  original wording stays reproducible independently of the migrated files.
* P3 detects the removed row by set comparison (`SCN-105` absent from the table), not by a row
  message; the renamed selector is reported per selector. The procedure therefore reports both
  defects, with the removed row surfacing as "unmapped".
* Selector resolution is textual (`def <name>(` in the named module). It shows that a mapping
  points at an existing check; it does not execute the tests and does not establish that a mapped
  check is adequate for the criterion. Accepting the mapping's meaning remains a review task.
* P4 collected 27 ids because the working tree also held the uncommitted `SETUP-01.feature`
  (SCN-301–SCN-308); the committed change set holds 19 (SCN-101–108, SCN-201–205, SCN-401–406).
  Uniqueness and the one-tag-per-scenario property hold for the 27-id set and therefore for any
  subset of it.
* The script is deliberately not committed as a test: the repository adds no permanent test that
  asserts documentation prose, and no runner or gate is introduced by this story.
* Author-side correction during the checks: the first P1 run compared bare `AC-x.y` heading labels
  against `@`-prefixed tags and reported failures; the comparison was corrected and the run
  repeated. No artifact was changed to make a check pass.
* The lifecycle/project-definition documents and these feature files were already checked once
  before this story's criteria were written
  (`docs/reviews/lifecycle-specification-migration.md`); that record's results are not restated
  as verified here, and its hash table identifies its own checked versions.

## Appendix: analysis script (throwaway, not committed)

Kept here so the checks above are reproducible. It reads the working tree and the M0 record at
`efa824b5`; it writes nothing.

```python
#!/usr/bin/env python3
"""Throwaway analysis for FT-03 (#39): migration fidelity, mapping resolution, identity.

Run from the repository root:  python3 /tmp/ft03_analysis.py
Not a committed test. It reads the working tree and the M0 record at MIGRATION_REV.
"""
import pathlib
import re
import subprocess

MIGRATION_REV = "efa824b5b225db74c7ddba50365dad918d3212cc"
M0_INDEX = pathlib.Path("docs/stories/M0-foundation.md")


def old_m0():
    """The M0 record as committed at the migration revision."""
    return subprocess.run(
        ["git", "show", f"{MIGRATION_REV}:{M0_INDEX}"],
        capture_output=True, text=True, check=True,
    ).stdout


def gherkin_blocks(md):
    return [[line.strip() for line in block.splitlines() if line.strip()]
            for block in re.findall(r"```gherkin\n(.*?)```", md, re.S)]


def old_labels(md):
    return re.findall(r"###\s+(AC-[\d.]+)[^\n]*\n+```gherkin", md)


def scenario_bodies(path):
    bodies, current = [], None
    for raw in pathlib.Path(path).read_text().splitlines():
        line = raw.strip()
        if not line or line.startswith("@"):
            continue
        if line.startswith(("Scenario:", "Scenario Outline:")):
            current = [line]
            bodies.append(current)
            continue
        if line.startswith(("Rule:", "Feature:", "Examples:")):
            current = None
            continue
        if current is not None:
            current.append(line)
    return bodies


def scenario_tags(path):
    tags, pending = [], []
    for raw in pathlib.Path(path).read_text().splitlines():
        line = raw.strip()
        if line.startswith("@"):
            pending += line.split()
        elif line.startswith(("Scenario:", "Scenario Outline:")):
            tags.append(pending)
            pending = []
        elif line.startswith(("Rule:", "Feature:")):
            pending = []
    return tags


def check_mapping(md_text):
    """Return (rows, scenario-id counts, problems) for a mapping-table text."""
    problems, counts = [], {}
    rows = re.findall(
        r"^\|\s*(AC-[\d.]+)\s*\|\s*(SCN-\d+)\s*\|(.*?)\|\s*([^|]*)\|$", md_text, re.M
    )
    for _ac, scenario, selectors, _scope in rows:
        counts[scenario] = counts.get(scenario, 0) + 1
        found = re.findall(r"`([\w/.\-]+\.py)::(\w+)`", selectors)
        if not found:
            problems.append(f"{scenario}: row lists no pytest selector")
        for path, function in found:
            source = pathlib.Path(path)
            if not source.exists():
                problems.append(f"{scenario}: {path} does not exist")
            elif not re.search(rf"^def {re.escape(function)}\(|^def {re.escape(function)}$", source.read_text(), re.M):
                problems.append(f"{scenario}: {path}::{function} resolves to no test function")
    return rows, counts, problems


report = []
old_md = old_m0()
old_blocks, labels = gherkin_blocks(old_md), old_labels(old_md)
ft01 = scenario_bodies("docs/stories/FT-01.feature")
ft02 = scenario_bodies("docs/stories/FT-02.feature")
migrated = ft01 + ft02
tag_sets = scenario_tags("docs/stories/FT-01.feature") + scenario_tags("docs/stories/FT-02.feature")

# P1 / SCN-402
report.append(f"P1 blocks: old={len(old_blocks)} new={len(migrated)} (FT-01 {len(ft01)}, FT-02 {len(ft02)})")
report.append("P1 line mismatches after indentation strip: "
              + str([i for i, (a, b) in enumerate(zip(old_blocks, migrated)) if a != b] or "none"))
report.append("P1 original AC labels retained as tags: "
              + str(all(("@" + want) in tags for want, tags in zip(labels, tag_sets))))

# P2 / SCN-403
index_text = M0_INDEX.read_text()
rows, counts, problems = check_mapping(index_text)
feature_ids = re.findall(r"@(SCN-\d+)", pathlib.Path("docs/stories/FT-01.feature").read_text()
                         + pathlib.Path("docs/stories/FT-02.feature").read_text())
report.append(f"P2 mapping rows: {len(rows)}; scenario ids in features: {len(set(feature_ids))}")
report.append("P2 every scenario in exactly one row: "
              + str(set(counts) == set(feature_ids) and all(n == 1 for n in counts.values())))
report.append("P2 unresolvable selectors: " + str(problems or "none"))
report.append("P2 distinct resolved selectors: " + str(len(
    {m for _a, _s, c, _x in rows for m in re.findall(r"`([\w/.\-]+\.py::\w+)`", c)})))

# P3 / SCN-404: the same procedure against a deliberately broken copy
broken = re.sub(r"^\|\s*AC-1\.5\s*\|\s*SCN-105\s*\|.*\n", "", index_text, flags=re.M)
broken = broken.replace("test_health_reports_contract_and_fixture_status", "test_nonexistent_selector")
_b_rows, broken_counts, broken_problems = check_mapping(broken)
report.append("P3 broken copy -> unmapped scenario reported: " + str("SCN-105" not in broken_counts))
report.append("P3 broken copy -> problems reported: " + str(broken_problems))

# P4 / SCN-406
single, described, all_ids = True, True, []
for feature in sorted(pathlib.Path("docs/stories").glob("*.feature")):
    text = feature.read_text()
    header = next(line for line in text.splitlines() if line.startswith("@"))
    if not re.search(rf"@{feature.stem}\b", header) or not re.search(r"@issue-\d+", header):
        described = False
    for tags in scenario_tags(str(feature)):
        if len([t for t in tags if t.startswith("@SCN-")]) != 1:
            single = False
    all_ids += re.findall(r"@(SCN-\d+)", text)
report.append(f"P4 scenario ids collected: {len(all_ids)}; duplicates: "
              + str([i for i in set(all_ids) if all_ids.count(i) > 1] or "none"))
report.append("P4 exactly one @SCN tag per scenario: " + str(single))
report.append("P4 every feature file names its story id and issue tag: " + str(described))

# P5 evidence for SCN-401 and SCN-405
report.append("P5 index gherkin blocks: " + str(index_text.count("```gherkin"))
              + "; canonical-scenario links: " + str(index_text.count("Canonical scenario:")))
form = pathlib.Path(".github/ISSUE_TEMPLATE/user-story.yml").read_text()
report.append("P5 intake form fields: " + str(re.findall(r"^\s+id:\s*(\w+)", form, re.M)))
for path in ("docs/STATUS.md", "docs/stories/M0-foundation.md",
             "docs/traceability-issue-map.md", "docs/reviews/lifecycle-specification-migration.md"):
    hits = [line.strip() for line in pathlib.Path(path).read_text().splitlines()
            if "pytest checks" in line or "Gherkin runner" in line
            or "not executed as Gherkin" in line or "author verification record" in line]
    report.append(f"P5 {path}: " + " | ".join(hits[:3]))

print("\n".join(report))
```
