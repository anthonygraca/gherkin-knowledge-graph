# AI-02 — Optional inference executes on the same machine

**Issue:** [#31](https://github.com/anthonygraca/gherkin-knowledge-graph/issues/31) · **Parent:** F-08
[#14] · **Milestone:** M3 · **Owner:** A; B/C review boundaries.
**Canonical criteria:** [AI-02.feature](AI-02.feature) (refinement draft, 6 scenarios).
**Status:** **blocked** on owner acceptance of a concrete local model/runtime/licence/hardware manifest.
The external Ollama endpoint does **not** satisfy this story.

## Scope

Optional same-machine inference via the existing CocoIndex/provider boundary; reject remote endpoints,
redirects/proxies, and implicit downloads; local weights provisioned explicitly; attributable execution
records; deterministic offline contract tests; opt-in live test with egress denied.

## Non-goals

Shared DGX services, cloud/remote Ollama, automatic model download, universal hardware support, retrieval
quality guarantees.

## Owner decisions

Exact model identifier, immutable weights digest, quantization, licence terms, runtime/version,
formatting instructions, platform, and measured storage/memory. Without these, no live criterion can be
claimed.

## Verification plan (planned, not executed)

Deterministic contract/error tests; opt-in live indexing/query with non-loopback egress denied; records
of weights digest/runtime/format versions; skipped live checks do not close the story.
