## Scope

Optional same-machine inference behind the existing `CandidateDiscovery` port; reject remote
endpoints, redirects/proxies, and implicit downloads; local weights provisioned explicitly;
attributable execution records; deterministic offline contract tests; opt-in live test with
non-loopback egress denied.

## Accepted manifest

* Model: `onnx-community/embeddinggemma-2-ONNX` at
  `daa72c51243991dfcaf9f9137d2c573d8f7790c0`, base `google/embeddinggemma-2` (Apache-2.0),
  text 270M, quantized ONNX.
* Combined weights digest:
  `sha256:b396bde0f7a85398c9c42d08a3c0b68d30952e91dcd408bfa327c727e86457a3`.
* Runtime: `onnxruntime` 1.32.0 `CPUExecutionProvider`, `tokenizers` 0.23.3, Python 3.12.16.
* Hardware: Intel Core i5-7500T, 4 logical CPUs, 15 GiB RAM, no GPU.
* Formatting: `ai02-code-query-v1/document-title-text-v1`; 768 dimensions; 512 max tokens.

## Non-goals

Shared DGX services, cloud/remote Ollama, automatic model download, universal hardware support,
retrieval-quality guarantees, and a vector database.

## Design

* `app/discovery/local_embedding.py`:
  * `OnnxEmbeddingRuntime` lazily imports the optional runtime, verifies installed files and the
    weights digest, runs CPU inference, and validates every vector (finite, expected dimension,
    non-zero norm) before L2 normalization.
  * `LocalEmbeddingCandidateDiscovery` implements `CandidateDiscovery`. It builds an in-memory
    corpus per baseline, embeds source/test documents for scenario queries and scenario documents
    for requirement queries, and ranks by cosine similarity. It exposes `binding_for(baseline)`
    and `index_revision` as `sha256` over the resolved commit, artifact IDs/paths/revisions/content
    hashes, model version, weights digest, formatting version, and dimension.
* `ProviderRegistry` registers `local-embeddinggemma` only when `CTA_LOCAL_EMBEDDING=1`; `fake`
  remains the default. A remote endpoint is `400 invalid-request` before any connection. Missing
  weights/digest/runtime and malformed embeddings are `503 retrieval-unavailable`.
* `backend/pyproject.toml` carries the optional `local-embedding` extra; the default suite and CI
  do not install or import it.

## Shared CandidateDiscovery contract cases

The offline tests exercise the real `LocalEmbeddingCandidateDiscovery.discover` boundary; only the
`EmbeddingRuntime.embed` implementation is substituted. The live run replaces that substitution
with `OnnxEmbeddingRuntime` and reuses the same cases.

| Case | Test selector | Independent input/expectation |
|---|---|---|
| Port identity and no write surface | `test_provider_satisfies_the_port_and_has_no_write_surface` | Provider satisfies `CandidateDiscovery`; no accept/reject/write vocabulary |
| Ranking and relation filters | `test_contract_ranks_and_filters` | `SCN-001` gives a nonempty ranked list; source ids equal the requested id; `implemented_by` selects sources, `exercised_by` selects tests, `verified_by` selects nothing |
| `top_k` trimming | `test_top_k_and_rank_trimming` | `top_k=1` yields one candidate at rank 1; `top_k=0` is rejected |
| Requirement and source behavior | `test_requirement_discovery_and_source_no_candidates` | `REQ-001` proposes scenarios; `CODE-001` returns an empty list |
| Index binding | `test_index_binding_tracks_content_and_model` | binding is `sha256`; baseline-a and baseline-b differ |
| No mutation | `test_discovery_does_not_write_links_evidence_or_findings` | accepted links, evidence, and findings are byte-equal before/after |
| Malformed output | `test_malformed_embedding_is_a_typed_failure` | non-finite vector → `RetrievalUnavailable`, no partial list |
| Remote endpoint | `test_remote_endpoint_is_refused_before_any_connection`, `test_remote_endpoint_route_is_a_400` | `InvalidRequest`/400 before a connection |
| Missing weights | `test_missing_model_directory_is_unavailable`, `test_onnx_runtime_refuses_missing_weights`, `test_missing_model_route_is_a_503` | `RetrievalUnavailable`/503, no download |
| Default remains fake | `test_default_registry_does_not_include_local` | effective registry is `["fake"]` without opt-in |

The canonical `SCN-3204` scenario additionally requires a known artifact with no eligible targets
to return an empty list while the API response retains provider/model/index provenance, and a
runtime that cannot report its model identity to fail explicitly rather than invent one.
